TRABAJO FUTURO

Proximos pasos para mejorar la prediccion clinica

Variables Temporales

Integrar senales vitales continuas (FC, PA, SpO2) para capturar tendencias de deterioro hemodinamico durante y despues de la cirugia.

Modelos de Series Temporales

Explorar arquitecturas LSTM o Transformers para modelar la evolucion temporal del estado del paciente, ya que el shock es un proceso evolutivo.

Umbral Dinamico

Investigar umbrales adaptativos que ajusten la sensibilidad segun el contexto clinico (tipo de cirugia, perfil de riesgo) para reducir fatiga de alertas.

Validacion Prospectiva

Implementar estudio prospectivo para evaluar rendimiento en condiciones clinicas reales y medir impacto en tiempos de respuesta.

Dataset Multicentrico

Colaborar con otras instituciones para aumentar tamano y diversidad del dataset, mejorando generalizacion y mitigando sesgos de poblacion.

Arquitectura Escalable

El pipeline parametrizado con Apache Airflow permite cambiar algoritmos y ajustar hiperparametros mediante configuracion YAML, sin modificar codigo.
