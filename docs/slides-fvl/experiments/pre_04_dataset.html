DATASET

Datos de la Fundacion Valle del Lili (FVL)

Caracteristicas del Dataset

  • Fuente: Registros quirurgicos de la FVL, Cali, Colombia
  • Poblacion: Pacientes de cirugia mayor no cardiaca
  • Tipo: Variables tabulares estaticas pre e intraoperatorias
  • Variable objetivo: Shock hemorragico postoperatorio (binaria)
  • Desbalance: Proporcion 2.1:1 entre casos negativos y positivos

Variables con Mayor Senal Predictiva

  • EDAD (56.36%): Edad avanzada implica menor reserva fisiologica
  • SANGRADO_MAYOR (22.65%): Exposicion directa al factor etiologico
  • HB_PREQX (18.37%): Hemoglobina preoperatoria indica capacidad de compensacion

Limitaciones del Dataset

Tamano muestral limitado y naturaleza estatica de las variables (sin series temporales de signos vitales). Los resultados deben interpretarse como validacion preliminar, no garantizan transferencia directa al entorno clinico real.
