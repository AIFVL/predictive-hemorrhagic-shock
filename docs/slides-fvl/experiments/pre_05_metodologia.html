CRISP-DM: Estandar para proyectos de mineria de datos e IA

1. Comprension del Negocio

Formulacion del problema, analisis del contexto clinico FVL, definicion de objetivos y restricciones eticas.

2. Comprension de Datos

Exploracion del dataset FVL, identificacion de variables relevantes, analisis de distribuciones y valores atipicos.

3. Preparacion de Datos

Limpieza, transformacion, codificacion, seleccion de features y balanceo con SMOTE (proporcion 2.1:1).

4. Modelado

5 experimentos secuenciales con 7 algoritmos: CatBoost, Decision Tree, LightGBM, Lasso, NB, Random Forest, XGBoost.

5. Evaluacion

AUC-ROC, sensibilidad, especificidad, F2-score. Interpretabilidad con SHAP para validacion clinica transparente.

6. Arquitectura Propuesta

Pipeline parametrizado con Apache Airflow y patron Factory para futuros procesos de analisis con diferentes modelos y datasets.

Validacion Cruzada Estratificada (k-fold)

Cada pliegue mantiene la misma proporcion de casos positivos (shock) y negativos (no shock), aspecto critico dado el desbalance inherente de la variable objetivo.
