ARQUITECTURA PROPUESTA

Pipeline parametrizado para futuros procesos de analisis

Apache Airflow

Orquestador que estructura el flujo de ejecucion mediante DAGs (Grafos Aciclicos Dirigidos), automatizando dependencias entre limpieza, entrenamiento y evaluacion.

Patron Factory + YAML

Desacoplamiento entre configuracion y ejecucion. Cambiar algoritmos o hiperparametros se resuelve editando un archivo YAML, sin modificar codigo.

Interfaz Streamlit

Editor visual de configuraciones que valida formato YAML, permitiendo a investigadores clinicos configurar experimentos sin conocimientos tecnicos avanzados.

Organizacion Automatica

Reportes, graficas y metricas se clasifican automaticamente en carpetas por experimento y algoritmo, facilitando consulta y comparacion sistematica.

Proposito

Esta arquitectura no es un despliegue clinico. Es una propuesta de infraestructura para futuros procesos de analisis de datasets usando diferentes modelos, permitiendo experimentacion sistematica, trazable y reproducible.
